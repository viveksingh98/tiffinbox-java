# c2-unit25 — Byte and Character Streams: InputStream, Reader, Buffers (JDK 25.0.4.1)
Run the six compact source files directly, no flags: `java Streams.java` · `java Serial.java` · `java Counted.java` · `java Silent.java` · `java FourWays.java` · `java WrongCharset.java`.
`Streams.java` — the full chain out (`BufferedWriter`→`OutputStreamWriter`→`FileOutputStream`) and back, plus a bare `FileInputStream`; prints `bytes on disk:  106`, the four anchor bills and `month total:    24300` (6/6 byte-identical, md5 `e552366a…`). `Serial.java` — `14 bytes as CSV` vs `117 bytes as Java serialization` (md5 `46d10640…`). `Counted.java` — a counting `OutputStream` on the file: `106 write calls` raw vs `1` buffered (md5 `eb0ae15f…`). `Silent.java` — the **three** failures that do not announce themselves: unclosed writer → `0 bytes`, UTF-16 read as ISO-8859-1 → 41 chars of mojibake, and a `close()` that throws while the body throws — a hand-written `finally` loses your exception, `try`-with-resources keeps it as `getSuppressed()[0]` (3/3 byte-identical, md5 `2282e631…`).
`FourWays.java` — **takes about a minute**: it writes one 52,428,800-byte file and reads it four ways (unbuffered `FileInputStream`, `BufferedInputStream`, `FileChannel` + 64 KB `ByteBuffer`, memory-mapped), adding up every byte each time. The `checksum 3463577600` is identical for all four; the **timings are not fixed** and move on every machine — on this Mac, 4 runs gave `45863/40136/32354/28234 ms` unbuffered against `661/727/571/525 ms` buffered, i.e. 53–69×. The NIO unit re-uses this same capture: run it from there with `java ../c2-unit25/FourWays.java`.
`WrongCharset.java` — **exits 1 on purpose**: `MalformedInputException: Input length = 1` at `WrongCharset.java:11`; the real trace is **nine** `at` frames and the slide shows three with `… 6 JDK frames elided` marked. JDK 25.0.4.1 frame numbers, re-capture on JDK 27.
Every demo creates its temp directory with `Files.createTempDirectory(Path.of("."), …)`, i.e. **beside the source file**; all of them delete it **except `WrongCharset.java`**, which crashes first — clean up with `rm -rf tiffinbox-charset-*` (`.gitignore` covers it).
