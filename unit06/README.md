# Unit 06 — Operators and Expressions: Ravi's Monthly Bill

- `Bill.java` — arithmetic, precedence, comparison and logical operators on Ravi's bill; prints `Monthly bill: 7200` … `Regular: true, big spender: true`. Run: `java Bill.java`
- `Skipped.java` — the "break it on purpose" file: `7 / 30 * 100` gives `Skipped: 0.0%` (int division), the `(double)` cast fixes it, `formatted` rounds it to `23.3%`. Run: `java Skipped.java`
- `Shortcuts.java` — the two slide-3 shortcuts `-=` and `++`; prints `Bill: 7000, meals: 3`. Run: `java Shortcuts.java`
- Needs JDK 25 (compact source files + `IO.println`, JEP 512). Verified on JDK 25.0.4.1.
