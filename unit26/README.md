# Unit 26 — Files: Read and Write with java.nio

- `SaveCustomers.java` — `Path.of("customers.csv")` + `Files.writeString` (creates, writes, closes; a second run replaces the file); prints `Saved customers.csv: true, 34 bytes`. Run: `java SaveCustomers.java` — the file lands in the working directory (the folder you run `java` from).
- `ReadCustomers.java` — writes the same file first, then `Files.readAllLines` (a `List<String>`, one element per line) and `Files.readString` (one String, newlines kept); prints `2 customers on file` / `- Ravi,2,120,true` / `- Meera,1,150,false` / the two lines again / a blank line. Run: `java ReadCustomers.java`
- `AppendCustomers.java` — `Files.writeString(path, "Sunil,1,120,true\n", StandardOpenOption.APPEND)`, then `Files.lines` inside try-with-resources + `count()`, then `getLast()`; prints `3 customers on file` / `Sunil,1,120,true`. Use `StandardOpenOption.CREATE, StandardOpenOption.APPEND` when the file might not exist yet. Run: `java AppendCustomers.java`
- `BreakFile.java` — the "break it on purpose" file: reads `customer.csv` (no `s`) and dies with `Exception in thread "main" java.nio.file.NoSuchFileException: customer.csv` … `at BreakFile.main(BreakFile.java:2)`. `FixFile.java` catches `NoSuchFileException` and prints `No file yet, starting empty: customer.csv`. Run: `java BreakFile.java`, then `java FixFile.java`.
- Needs JDK 25 (compact source files + `IO.println`, JEP 512; `Path`, `Files`, `IOException`, `NoSuchFileException`, `StandardOpenOption` need no import — `java.base` is imported). Verified on JDK 25.0.4.1.
