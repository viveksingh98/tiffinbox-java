# c2-unit31 — The Module System: module-info.java Explained (JDK 25.0.4.1)
Build and run the real modular project, no flags: `javac -d mods --module-source-path src $(find src -name '*.java')` then `java --module-path mods -m tiffinbox.app/com.tiffinbox.app.Main` — prints `Meera -> 3600` / `Priya -> 3600` / `Ravi -> 5400` / `Sunil -> 5400` and then `tiffinbox.app` / `true` / `tiffinbox.api` (3/3 runs byte-identical, md5 `6848eaf4…`). `src/` here is the **same `tiffinbox.api` source** that units 32 and 33 ship — 32 only adds `Receipt` and `requires transitive java.net.http`.
`plain/Legacy.java` is the unnamed-module capture: `javac -d plainout plain/Legacy.java` then `java -cp plainout com.tiffinbox.legacy.Legacy` prints `this class module: null` (3/3 byte-identical, md5 `48b18c94…`); `jdeps --list-deps plainout` prints its `requires` list — `java.base`, `java.net.http`, `java.sql`.
Automatic modules: `jar --create --file lib/legacy.jar -C plainout .` then `java --module-path lib --describe-module legacy` → `legacy … automatic`; rebuild with `printf 'Automatic-Module-Name: tiffinbox.legacy\n' > mf.txt; jar --create --file lib/legacy.jar --manifest mf.txt -C plainout .` and the same command answers to `tiffinbox.legacy`.
Read the graph back with `java --module-path mods --describe-module tiffinbox.api` (and `tiffinbox.app` — its two `requires` lines come out in either order), and `jdeps --module-path mods -s mods/tiffinbox.app`. Versions are opt-in: `javac --module-version 1.0 …` is what makes `--describe-module` print `tiffinbox.api@1.0`.
The two broken copies are meant to fail: `javac -d bad1 --module-source-path src-nonexported $(find src-nonexported -name '*.java')` gives **1 error**, *which does not export it*; `javac -d bad2 --module-source-path src-norequires $(find src-norequires -name '*.java')` gives **4 errors**, *does not read it*; and `java --module-path modsonly -m tiffinbox.app/com.tiffinbox.app.Main` (a module path holding only `tiffinbox.app`) gives `FindException: Module tiffinbox.api not found, required by tiffinbox.app`.
