# c2-unit33 · jlink and jpackage — ship TiffinBox as a runtime image
`s2/` is a byte-for-byte copy of `c2-unit32/s2/` — the same four modules, not a lookalike. That is what makes the md5 identity in step 3 mean anything.
1. `export JAVA_HOME=/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home; export PATH=$JAVA_HOME/bin:$PATH` (JDK 25.0.4.1; `$JAVA_HOME/jmods` must exist)
2. Compile + run on the module path: `javac -d mods2 --module-source-path s2 $(find s2 -name '*.java')` then `java --module-path mods2 -m tiffinbox.app/com.tiffinbox.app.Pay`
3. Runtime image: `jlink --module-path "$JAVA_HOME/jmods:mods2" --add-modules tiffinbox.app,tiffinbox.card,tiffinbox.wallet --launcher tiffinbox=tiffinbox.app/com.tiffinbox.app.Pay --output image2 --strip-debug --no-header-files --no-man-pages` then `./image2/bin/tiffinbox` (md5 `8369830e…`, same as step 2). The image content is 44,973,010 bytes on every build; `du -sm` reports 43 or 44 for that same content because `du` counts allocated blocks.
4. Native bundle + installer: `jpackage --type app-image --name TiffinBox --module-path "$JAVA_HOME/jmods:mods2" --module tiffinbox.app/com.tiffinbox.app.Pay --add-modules tiffinbox.app,tiffinbox.card,tiffinbox.wallet --dest dist` (`du -sm` 45, 3/3; swap `--type dmg --dest dmgout` for the installer — three builds gave 15,988,846 / 15,987,740 / 15,987,619 bytes). `codesign -dv dist/TiffinBox.app` reports `Signature=adhoc`, `TeamIdentifier=not set` — not distributable.
5. Break it three ways: `--add-modules tiffinbox.app` alone → `gateways found: 0` (4 modules); `javac -d plainout plain/Legacy.java` then `jlink --module-path "$JAVA_HOME/jmods:plainout" --add-modules Legacy --output imagex` → `FindException: Module Legacy not found`; `jar --create --file lib/legacy.jar -C plainout .` then `jlink --module-path "$JAVA_HOME/jmods:lib" --add-modules legacy --output imagex` → `Error: automatic module cannot be used with jlink`. And for the split package, `breaks/split-package/` adds a `tiffinbox.extra` module that declares `com.tiffinbox.api` again plus an app `module-info.java` that requires both — run it **from this folder** on a clean `s2/` so the printed paths match the slide: `cp -R breaks/split-package/tiffinbox.extra s2/` then `cp breaks/split-package/tiffinbox.app/module-info.java s2/tiffinbox.app/` then `javac -d mods2 --module-source-path s2 $(find s2 -name '*.java')` → exit 1, `s2/tiffinbox.app/module-info.java:1: error: module tiffinbox.app reads package com.tiffinbox.api from both tiffinbox.api and tiffinbox.extra`, `1 error` (3 runs byte-identical, md5 `24740261…`).
