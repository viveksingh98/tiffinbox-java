# Unit 03 — Your First Program: Hello, TiffinBox
Compact form (JDK 25): `java Hello.java` → prints `Hello, TiffinBox!`
Classic form: `cd classic && java Hello.java` → same output
Broken on purpose (missing semicolon): `cd broken && java Hello.java` → `Hello.java:2: error: ';' expected`
Verified on JDK 25.0.4.1 (`/opt/homebrew/opt/openjdk@25/bin/java`).
