# Unit 33 — Packages, Imports and Project Structure

- Layout: `src/main/java/com/tiffinbox/` holds the shipped code (`package com.tiffinbox;` on line one of every file — the folders below `src/main/java` ARE the package, dot for slash); `src/test/java/com/tiffinbox/` is empty until Unit 35's `BillingTest.java`. No `pom.xml` yet — Unit 34 adds Maven.
- `Billing.java` — Unit 10's `calculateBill` as a normal `public class` (two overloads; `Main` calls the three-argument one). `Main.java` — `import java.util.List;`, prints `3 customers on file` / `Ravi pays 7200`. `ModuleImports.java` — JDK 25's `import module java.base;` (JEP 511) using `List`, `ArrayList`, `LocalDate`; prints `[Ravi, Meera, Sunil] 2026-09-01`.
- Compile from this folder: `javac -d out src/main/java/com/tiffinbox/*.java` → `out/com/tiffinbox/Billing.class`, `Main.class`, `ModuleImports.class`. Run by full name: `java -cp out com.tiffinbox.Main` and `java -cp out com.tiffinbox.ModuleImports`. Quick check without `-d`: `java src/main/java/com/tiffinbox/Main.java` (source launcher compiles the siblings, JEP 458).
- Break it on purpose: `cd out/com/tiffinbox && java Main` → `Error: Could not find or load main class Main` / `Caused by: java.lang.NoClassDefFoundError: Main (wrong name: com/tiffinbox/Main)`; from the root `java -cp out Main` → `Caused by: java.lang.ClassNotFoundException: Main`. Fix: stand at the root of the class tree and use the full name.
- Needs JDK 25 (`java.lang.IO` is an ordinary class, JEP 512; module import declarations, JEP 511). Verified on JDK 25.0.4.1 (`javac 25.0.4.1`).
