# Unit 02 — Install JDK 25 and IntelliJ (Mac + Windows)
`Main.java` is the first-run check: the sample program IntelliJ generates, with the text changed to "Hello, TiffinBox!".
Run from a terminal (JDK 25 on your PATH): `java Main.java`
Expected output: `Hello, TiffinBox!`
Or in IntelliJ: open the project, click the green ▶ next to `main`. Verified on JDK 25.0.4.1.
