### NESTED — two refusals, then the labelled manager (brief ⚑7, S4.14)

Said: **"NESTED needs savepoints, and this manager has none to offer"** — both messages on the slide. On the manager Boot builds
(`JpaTransactionManager`, `nestedTransactionAllowed as built: false`, printed by the JVM before the first cell) NESTED inside a
transaction is refused with the first message, `NestedTransactionNotSupportedException: Transaction manager does not allow nested

second message, `JpaDialect does not support savepoints - check your JPA provider's capabilities`. Only on the labelled `htm` run do
the savepoint lines appear: H2's own trace prints `setSavepoint("SAVEPOINT_1")`, `SAVEPOINT "SAVEPOINT_1"`, and for inner-fails
`ROLLBACK TO SAVEPOINT "SAVEPOINT_1"` and `releaseSavepoint`. The unscoped reading is refused per sentence by the prose gate (S4.14).
The two rollback-only messages differ by manager (the brief's hazard): this unit speaks only `JpaTransactionManager`'s, "Transaction
silently rolled back because it has been marked as rollback-only"; the `htm` run never reaches a rollback-only commit.
