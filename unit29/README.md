# Unit 29 — Streams: Reports in One Line

- `Reports.java` — Unit 27's `record Customer` list; `stream().filter(Customer::isVeg).map(Customer::name).toList()` → `[Ravi, Sunil]`; `mapToInt(...).sum()` → `Monthly revenue: 15300`; `sorted(Comparator.comparing(...).reversed())` → `[Ravi 7200, Meera 4500, Sunil 3600]`; `collect(Collectors.joining(", "))` → `Reminder to: Ravi, Meera, Sunil`. Run: `java Reports.java`
- `Lazy.java` — a `filter` that prints its name plus a print line before `toList()`; prints `pipeline built, nothing ran yet` / `filter Ravi` / `filter Meera` / `filter Sunil` / `[Ravi, Sunil]` — nothing runs until the terminal operation asks. Run: `java Lazy.java`
- `Takings.java` — Unit 18's `Order` + `MealType`, four orders; `groupingBy(Order::type, TreeMap::new, summingInt(Order::total))` → `{VEG=360, NON_VEG=150, JAIN=130}`; `counting()` → `{VEG=2, NON_VEG=1, JAIN=1}`; `Takings: 640`. Run: `java Takings.java`
- `BreakStream.java` — the "break it on purpose" file: one stream used twice prints `2` then `java.lang.IllegalStateException: stream has already been operated upon or closed` (`at BreakStream.main(BreakStream.java:6)`); fix = call `customers.stream()` again. Run: `java BreakStream.java`
- Needs JDK 25 (compact source files + `IO.println`, JEP 512; `List`, `Comparator`, `Collectors`, `TreeMap` come from `java.base`, so no import lines). Verified on JDK 25.0.4.1.
