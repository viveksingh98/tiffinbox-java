# Unit 30 — Optional: The End of null Checks

- `NullFinder.java` — the hook: `findByName` still answers `return null;`, and `findByName(customers, "Asha").monthlyBill()` dies with `java.lang.NullPointerException: Cannot invoke "NullFinder$Customer.monthlyBill()" because the return value of "NullFinder.findByName(java.util.List, String)" is null` (`at NullFinder.main(NullFinder.java:3)`). Run: `java NullFinder.java`
- `Finder.java` — `Optional<Customer> findByName(...)` = Unit 29's `stream().filter(...).findFirst()`; prints `Optional[Customer[name=Meera, mealsPerDay=1, pricePerMeal=150, isVeg=false]]` / `Optional.empty`, then reads the box safely: `map(Customer::monthlyBill).orElse(0)` → `4500` / `0`, `ifPresent` → `Sunil is on the list`, `ifPresentOrElse` → `no such customer`. Run: `java Finder.java`
- `WhenAbsent.java` — `orElseThrow(() -> new IllegalArgumentException(...))` → `Ravi pays 7200`; `orElseGet(() -> new Customer("Guest", 1, 120, true))` on an empty box → `Customer[name=Guest, mealsPerDay=1, pricePerMeal=120, isVeg=true]`. Run: `java WhenAbsent.java`
- `BreakOptional.java` — the "break it on purpose" file: `findByName(customers, "Asha").get()` → `java.util.NoSuchElementException: No value present` (`at java.base/java.util.Optional.get(Optional.java:143)` / `at BreakOptional.main(BreakOptional.java:3)`). Run: `java BreakOptional.java`
- Needs JDK 25 (compact source files + `IO.println`, JEP 512; `Optional`, `List`, `Stream` come from `java.base`, so no import lines). Unit 27's `record Customer` sits below `main` in every file. Verified on JDK 25.0.4.1.
