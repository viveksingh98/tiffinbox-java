# c2-unit27 — Sockets: A TCP Order Line for TiffinBox (JDK 25.0.4.1)
Six compact source files, **no flags**. Every server here binds **`InetAddress.getLoopbackAddress()`** — `127.0.0.1` only, never the wildcard, so nothing on your network can reach it. Check the port is free first: `lsof -nP -iTCP:8123 -sTCP:LISTEN`.

**Run order matters: one demo owns port 8123 at a time.** They all bind it, so a second one started while the first is up gives `java.net.BindException: Address already in use` — and `NoNewline.java` ends by sending `CLOSE`, which **stops the server**, so it is always the last thing you run against a given `OrderLine`. Stop the server between demos.
1. `java SocketFacts.java` — standalone. Proves `ServerSocket` is **not** a `Socket`, that one port serves two connections with different client ports, and that `interrupt()` leaves a thread blocked in `accept()` while `close()` ends it (6/6 byte-identical, md5 `1b88cbb0…`).
2. `java BrokenPipe.java` — standalone. The failure that fills production logs: the client closes with `setSoLinger(true, 0)` so `close()` sends a TCP **reset**, and the server keeps writing until `java.net.SocketException: Broken pipe`. A `CountDownLatch` gates it — **no `Thread.sleep` anywhere** (5/5 byte-identical, md5 `cc62a00c…`).
3. Pane A `java OrderLine.java`, then pane B `java OrderClient.java` — four orders plus `CLOSE`; the server exits by itself, never Ctrl-C. Server md5 `960ab8e0…`, client md5 `60036f90…`, `order line closed, revenue booked: 24300`. Same server over netcat: `printf 'ORDER Ravi 2\nORDER Meera 1\nCLOSE\n' | nc localhost 8123` (md5 `fde39929…`).
4. With an `OrderLine` running, `java NoNewline.java` — twelve bytes with no `\n` give `SocketTimeoutException: Read timed out`, then the one missing byte releases the reply (5 paired runs byte-identical, md5 `13aa3d3c…`). It sends `CLOSE` at the end.
5. `java OrderDown.java` — with **nothing** listening: `java.net.ConnectException: Connection refused` at `OrderDown.main(OrderDown.java:5)`, exit code 1 (5/5, stdout md5 `39c1e7d0…` / stderr `dd78b3ae…`).
