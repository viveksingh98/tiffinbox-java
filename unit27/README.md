# Unit 27 — Parsing Data: CSV to Objects

- `ParseOne.java` — `"Ravi,2,120,true"` → `split(",")` → `Integer.parseInt` / `Boolean.parseBoolean` → `new Customer(...)`; prints `4 parts, first: Ravi` / `Customer[name=Ravi, mealsPerDay=2, pricePerMeal=120, isVeg=true]` / `Monthly: 7200` / `21` / `3` (String `+` joins, int `+` adds). Run: `java ParseOne.java`
- `LoadCustomers.java` — writes `customers.csv` (header + Ravi, Meera, Sunil) with a text block, then `load(path)` → `List<Customer>` via `parse(line)` (skips the header, `trim()`s every field); prints `Ravi: 7200` / `Meera: 4500` / `Sunil: 3600` / `3 customers, 15300 a month`. Run: `java LoadCustomers.java`
- `RoundTrip.java` — `toCsv()` mirrors `parse`; `save(customers, path)` builds the file with a `StringBuilder` and one `Files.writeString`; load 2, add Sunil, save, load again; prints `Loaded 2` / `Saved 3` + the four file lines. Run: `java RoundTrip.java`
- `BreakParse.java` — the "break it on purpose" file: the row `Sunil,two,120,true` kills the whole load with `java.lang.NumberFormatException: For input string: "two"` (`at BreakParse.parse(BreakParse.java:17)`). `FixParse.java` — try/catch `NumberFormatException` inside the loop: `Skipped line 4: For input string: "two" in 'Sunil,two,120,true'` / `2 customers loaded`. Run: `java BreakParse.java`, then `java FixParse.java`
- Needs JDK 25 (compact source files + `IO.println`, JEP 512; `Path`, `Files`, `List`, `ArrayList`, `StringBuilder` come from `java.base`, so no import lines). Every file writes `customers.csv` into the working directory first, so each run is self-contained. Verified on JDK 25.0.4.1.
