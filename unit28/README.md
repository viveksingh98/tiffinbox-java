# Unit 28 — Lambdas and Functional Interfaces

- `Lambdas.java` — Unit 27's `record Customer` below `main`; `Predicate<Customer> isVeg = c -> c.isVeg()` → `true false`; `Function` with the method reference `Customer::monthlyBill` → `7200`; a `Consumer` through `customers.forEach(print)` → `Ravi pays 7200` / `Meera pays 4500` / `Sunil pays 3600`; a `Supplier` walk-in → `Customer[name=Guest, mealsPerDay=1, pricePerMeal=120, isVeg=true]`; `isVeg.and(bigSpender)` → `true false`; `removeIf(isVeg.negate())` → `2 veg customers`; your own `@FunctionalInterface Discount` → `6480`. Run: `java Lambdas.java`
- `OldWay.java` — the same `isVeg` as an anonymous class (`new Predicate<>() { @Override public boolean test(Customer c) { ... } }`), the pre-Java-8 shape you will read in old code; prints `true`. Run: `java OldWay.java`
- `BreakCapture.java` — the "break it on purpose" file: `total += c.monthlyBill()` inside a lambda fails with `BreakCapture.java:4: error: local variables referenced from a lambda expression must be final or effectively final`. `FixCapture.java` — Unit 09's loop, then `customers.stream().mapToInt(Customer::monthlyBill).sum()`; prints `Revenue: 15300` twice. Run: `java BreakCapture.java`, then `java FixCapture.java`
- Needs JDK 25 (compact source files + `IO.println`, JEP 512; `Predicate`, `Function`, `Consumer`, `Supplier`, `List`, `ArrayList` come from `java.base`, so no import lines). Verified on JDK 25.0.4.1.
