# c2-unit29 — JSON Without Spring: Jackson via Maven (JDK 25.0.4.1 · Maven 3.9.16)
A complete Maven project — clone this folder, nothing else to install: one pinned dependency (`com.fasterxml.jackson.core:jackson-databind:2.22.2`), `maven.compiler.release=25`, `exec-maven-plugin:3.6.4`. Set `export JAVA_HOME=/opt/homebrew/opt/openjdk@25` first. `exec:java` does **not** compile by itself, so keep `compile` in front of it on a fresh clone.
Main demo: `mvn -q compile exec:java` → `write:` / `pretty:` / `read:   Ravi -> 7200`, the four bills, `month total: 24300`, `List.class gives you: java.util.LinkedHashMap` (6/6 runs byte-identical, md5 `30be12ee…`, exit 0).
Break it: `mvn -q compile exec:java -Dexec.mainClass=com.tiffinbox.JsonOops` → the caught `UnrecognizedPropertyException` with the field, the class, the four known properties and the path, then `lenient mapper: Ravi -> 7200` (6/6 byte-identical, md5 `53b17187…`, exit 0). Measure the mapper rule: `-Dexec.mainClass=com.tiffinbox.MapperCost` (timings, so they move every run).
See the three jars one line pulled in: `mvn dependency:tree`. See the trick that beats erasure: `javap -v -p target/classes/com/tiffinbox/'Json$1.class' | grep Signature:`. See `@JsonProperty` land in three places: `javap -v -p target/classes/com/tiffinbox/Customer.class | grep -E 'boolean isVeg|parameter 3|JsonProperty\('`. `hand-rolled/HandRolled.java` is the hook — `java hand-rolled/HandRolled.java` prints `as the last unit sent it -> 7200`, then dies twice on the same four fields in a different order (3/3 byte-identical, md5 `8743a0ea…`; the older `8a7daf58…` predates removing a unit number from the printed label and must not be re-used).
See the crash a raw `List.class` buys you: `mvn -q compile dependency:build-classpath -Dmdep.outputFile=cp.txt`, then `javac -Xlint:unchecked -cp "target/classes:$(cat cp.txt)" -d target/classes src/main/java/com/tiffinbox/Unchecked.java` (warning on line 11, md5 `41b95570…`) and `java -cp "target/classes:$(cat cp.txt)" com.tiffinbox.Unchecked` → `this line is fine: 4` then a `ClassCastException` at `Unchecked.java:13`, with the module-and-loader tail in full, exit 1 (3/3, md5 `89db0307…`).
Drop the braces and it does not compile — `breaks/NoBraces.java` is that panel, kept **outside** `src/main/java` so it cannot break `mvn compile`: `cd breaks && javac -cp "../target/classes:$(cat ../cp.txt)" -d "$TMPDIR/nb" NoBraces.java` → `NoBraces.java:7: error: TypeReference is abstract; cannot be instantiated` / `1 error`, exit 1. Without a subclass there is no superclass for Jackson to read.
**Build-time network:** at runtime nothing here leaves your machine, but the first `mvn compile` fetches the three Jackson jars from Maven Central; afterwards `mvn -o` works offline.
